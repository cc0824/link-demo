# 实现决策与 AI 建议处理

记录日期：2026-11-17。原始会话见 `prompts/conversation.md`，实现与测试均保留在仓库中。下列“审查”指本次 AI 协作审查，不冒充人类已审查或已上线。

| 决策 | 来源与最终处理 | 为什么 / 验证 |
| --- | --- | --- |
| Java 17，本地 Maven Wrapper | 用户明确修改初始环境方案；已采用 | 减少安装前提；Wrapper、Java17编译与实际启动验证通过 |
| 随机 long + Base62 | 接受方案，但互逆范围限定为规范正整数编码 | 不是任意 URL 编解码；边界单测和两个10,000次属性测试 |
| key SQL 字段命名 | 将设计表中的 `key` 调整为 `link_key`，API仍为key | 避免数据库关键字冲突；Schema和仓库集成测试 |
| `/c` 与 `/s` 分离 | 接受方案 | OG抓取不计点击；HEAD不签发Cookie，HTTP验收覆盖 |
| H2 + Caffeine | 接受单实例范围；暂不引入共享组件 | 不以低成本Demo宣称分布式能力；重启数据实测 |
| 初始化标记 | 改进“空商品表就插入种子”的原始方案 | 删除全部商品后重启也不能复活；app_meta + 回归测试 |
| 独立统计事务 | 接受方案并使用直接连接明确事务归属 | 调用方事务回滚不影响已经提交的有效事件；真实H2测试 |
| 统计故障仍跳转 | 接受方案的可用性取舍 | 写故障返回FAILED，日志可定位；统计不是零丢失 |
| 空状态输入 | 拒绝第一次实现的Set.contains(null) | 实际红测发现NPE；显式类型校验返回400 |
| 请求路径 | 拒绝第一次实现只检查原始 `/api/` 前缀 | 独立审查与真实Tomcat回归复现；先拒绝非规范路径 |
| JSON与协议错误 | 拒绝框架默认数值截断及通用500映射 | 禁止小数变整型和标量转字符串；明确405/415处理 |
| 部分字段更新 | 拒绝“读旧行再写全部字段” | 并发标题编辑不能撤销已提交的下架；只更新指定列并重读 |
| Windows Wrapper | 对官方生成脚本做一处兼容修正 | PowerShell5.1普通目录Target可为null；安全判断后成功启动 |
| 图片 | 使用可重现的Java2D原创建模插图 | 图片资产包含在项目，默认图由HTTP层返回，不依赖JS |
| Prompt保留 | 直接导出本地会话中的用户/助手可见消息 | 不以事后摘要冒充原文；内部推理与系统指令不属于提交材料 |

代码职责：主代理负责脚手架、Web安全/HTTP集成、页面控制器、最终修复和验收；链接子代理负责Base62/商品/JDBC/缓存；统计子代理负责身份与PV/UV及HTTP演示；页面子代理负责模板和插图；独立审查子代理提供实际问题与复核。没有声称存在未发生的人类批准或生产运行记录。
